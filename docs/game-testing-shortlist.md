# DOS game testing shortlist

These 42 games are a varied starting point for testing KairoDos. The exact ZIP
names and compressed sizes were checked on 2026-09-28 in the NAS eXoDOS pool:

`\\192.168.1.202\Public\Games\Roms\DOS\eXoDOS\eXo\eXoDOS`

Every pick has launch metadata in KairoDos's DOS catalog. That confirms a
configured launch path, not that the game has been boot-tested on an Android
device. Sizes are approximate MiB. The games are not part of this repository
or the app.

For a quick first pass, try **Tyrian 2000**, **Descent**, **The Incredible
Machine**, **Jazz Jackrabbit**, **X-COM: UFO Defense**, and **Theme Hospital**.
Together they exercise different control styles, audio, graphics, menus, and
saving. The larger CD and 3D games are useful later for storage and performance
testing.
