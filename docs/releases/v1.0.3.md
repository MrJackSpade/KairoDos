# v1.0.2

- The Exit and Return to library confirmations now appear above the game menu. Before, they opened behind it: hidden in portrait and partly covered in landscape.
- Configurations has a new **Game orientation** setting: Auto, Landscape or Portrait. Landscape and Portrait rotate the screen when a game starts; the library still follows the device. If the device keeps its orientation, as Retroid's Force landscape switch does, a message says rotation was attempted and a system setting is likely blocking it.

Install over v1.0.1 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
