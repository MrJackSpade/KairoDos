# v1.3.0

- A game still launches after you add or change files in its folder or archive, such as a BAT or configuration file, and its saves and settings stay with it. If the game had saved its own copy of a file you changed, KairoDos lists those files and asks whether to keep the saved copy or use the edited file.
- An edited game keeps its catalog title, artwork and launch options.
- Saves and settings now belong to a game's place in your DOS folder. Renaming or moving a game makes it a new game, and two copies of the same game no longer share saves.
- A game's settings follow it from its installer to the installed archive, including during the first session after installing.

Install over v1.2.2 or v1.2.3-test.1 to keep games, settings and saves. On first launch, existing saves and settings move to their games. If a save folder shared with another device already has a newer copy, KairoDos asks which one to keep. Both APK variants and the Play bundle have the same features.
