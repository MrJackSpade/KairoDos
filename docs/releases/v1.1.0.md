# v1.1.0

- The game you last played now appears under CONTINUE and also stays in its place in ALL GAMES. Before, pinning it removed it from the list below, and sometimes it was not pinned after you returned from a game.
- Installing an eXoDOS game, removing its installer and deleting a game now update the library right away instead of rescanning the whole folder. A removed installer can no longer be started from its old entry.
- Spell It Plus! (1989) is no longer listed as unreadable. Game ZIPs now read file names the way DOS archives store them.
- Large libraries open much faster. The library appears at once instead of freezing the app at launch, search finds games within seconds of starting the app, and Game settings no longer stutters.
- Editing a game's title or artwork updates its library row immediately.
- The ABC keyboard page has the full US rows, and every key shows its shifted character when Shift is locked. Caps Lock stays in step with the game, and the selected game on the second screen lists its year once.

Install over v1.0.4 to keep games, settings and saves. The library is converted to a faster format the first time this version starts. Both APK variants and the Play bundle have the same features.
