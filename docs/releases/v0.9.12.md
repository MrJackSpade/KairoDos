# v0.9.12

- Catalog files and update manifests are served directly from the repositories on main. Application releases publish only the signed APKs and Play AAB.
- Optional artwork import files contain references to repository images, reducing download size. Existing installed catalogs use their unchanged manifest address to obtain the new revision.
- Added catalog integrity checks covering repository sources, tracked artwork paths, part indexes, sizes and checksums. Existing metadata and controls are unchanged.
- Includes the catalog indexing responsiveness and D-pad Menu/Search navigation fixes from v0.9.11.
