# KairoDos 0.9.6

- The bundled catalog and automatic core updates now exclude reviewed adult records. Core artwork is limited to explicitly reviewed images.
- Import catalog files with Android's file picker, update installed catalogs, or remove them from the library menu. Installed metadata sits above the core catalog and below personal overrides.
- Catalog files carry their own update source. Updates validate identity, revision, checksums, metadata and artwork before replacing an installed archive.
- New core feeds replace the previous combined catalog. Older cached combined snapshots are not loaded by this version.

Separate catalog downloads and [installation instructions](https://github.com/MrJackSpade/KairoDos/blob/v0.9.6/docs/catalogs.md) are provided on GitHub. Games and personal settings are kept when a catalog is removed.
