# v1.6.1-test.4

Test build of KairoDos, for DOS games. It is not published to Google Play.

- Windows 3.1 games start again: Windows for Workgroups 3.11 stopped with "Invalid VxD dynamic link call to device number 0007" and quit to DOS, so Collection Chamber's Windows 3.1 games (Cosmology of Kyoto, Eastern Mind, Eastern Mind 2, 3-D Ultra Pinball: Creep Night and the rest) never started. The dynamic core now keeps track of the flags CMC, CLC, STC, MUL, IMUL, VERR and VERW change.
- Games whose Sound Blaster changes sample rate no longer stop with "SB: the mixer needs N frames, the queue holds M".
- Darker no longer hangs at the DOS prompt: the dynamic core now traps after a POPF that sets the trap flag, as a program single-stepping itself needs.
- Escape from Delirium no longer stops as it starts: the Gravis UltraSound no longer fails when a game unmasks its DMA channel before setting up its DMA.
- Collection Chamber installers whose program runs to hundreds of megabytes (Chewy: ESC from F5's native port) no longer run out of memory while the launch is worked out.
- A Collection Chamber game with several versions starts its standard one (dosbox.conf) first.
- Shipped controls never put Esc on Start: where a game had Esc on Start, Esc moves to Select and Select's binding moves to Start.

Install over v1.6.1-test.3, v1.6.1-test.2, v1.6.1-test or v1.6.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
