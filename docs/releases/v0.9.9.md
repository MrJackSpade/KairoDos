# KairoDos 0.9.9

Catalog actions now live in one **Catalog management** submenu: **Update catalogs**, **Import catalog file**, **Remove catalog**, and **Download missing images**.

**Update catalogs** checks the core catalog and only the optional catalogs already installed. If the core update fails, installed catalogs are still checked. Successful updates refresh metadata and artwork even when another check fails.

The submenu supports D-pad and controller hat navigation. Catalog contents and Play/GitHub artwork separation remain the same.
