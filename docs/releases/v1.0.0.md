# v1.0.0

- Redesigned menus: settings, game settings and the library menu open as full pages with rows, inline choices and confirmations instead of dialogs and drawers.
- The game menu no longer has Resume and Keep paused buttons, because opening it already pauses the game. Return to library and Exit ask for confirmation in a dialog.
- Each game's own files now stay unchanged. Everything a game writes, including its saves, is kept separately. Existing games convert automatically the first time they start after updating.
- New Menu › Configurations › Save folder setting keeps saved games in private app storage or in a folder you choose. Changing it moves your saved games there. If a game has saves in both places, you choose which copy to keep before anything moves. Moving saved games that have not been converted yet needs their game files in the library.
- After the first game, later games started in the same session no longer return straight to the library when a shader such as CRT EasyMode is enabled.
- Running games keep running when the device configuration changes, for example when you attach a keyboard, switch dark mode or change the display size.
- Choosing Library in a game started from an external frontend returns to that frontend.
- When Download missing images fails, the result names the reason, such as no internet connection.

Install over the previous signed KairoDos release to keep games and settings. Saved games converted by this version cannot be read by earlier versions, so do not reinstall an older release afterwards. Both APK variants and the Play bundle have the same features.
