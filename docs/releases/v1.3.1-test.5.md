# v1.3.1-test.5

Test build of KairoDos, for DOS games. It is not published to Google Play.

- A game's Version setting keeps the eXoDOS presets and adds Custom. Custom shows the DOSBox settings and startup commands, starting from the preset the game had, and works for any game, including ones without a preset. The version choice on a game's first play is back.
- DOSBox settings shows each setting with the value the game runs with, and changes it for that game; Startup commands replaces the autoexec.
- Startup commands and other text settings can take several lines.
- A long setting value is shortened on its row instead of the setting's name.
- The on-screen keyboard's joystick tab shows a joystick icon.
