# v1.3.1-test.6

Test build of KairoDos, for DOS games. It is not published to Google Play.

- A game file opened from another app, such as a frontend like Neostation, opens as the library game with the same content, with that game's saves and settings.
- Games the library has already read are never hashed again; the scan shows its progress on one line.
- Disk choices list the game's own disks first, then Other.
- Updating the catalog no longer holds up the screen.
- On two screens, both come back after Home, and swapping them no longer stops the app.
