# v1.6.1

- Collection Chamber games: put a Collection Chamber download (its Install-*.exe, with any .D01 parts beside it) in your DOS folder. The library lists it as the game's installer; Play installs it and starts the game its shortcuts start, with the DOSBox setup the download brings, then offers to delete the installer, as with eXoDOS. No catalog entry is needed for this.
- The catalog knows every Collection Chamber DOS and Windows 3.1 installer, before and after installing: it joins the eXoDOS game where there is one, and the others have their own title, tags, box art, screenshot and description. A download with several versions starts the one its main shortcut starts.
- Two Collection Chamber downloads use Inno Setup installers, which are not supported yet.
- Split Keyboard: on a screen 16:10 or wider, the on-screen keyboard splits into two halves that fill the empty space beside the game picture, which keeps its size, whenever that space is at least a sixth of the screen's width on each side. The Joystick page puts its directions on the left and its buttons on the right, and the touchpad has a surface in each half. Turn it off in Controls › Keyboard › Split Keyboard.
- On-screen keyboard keys and tabs keep their labels on one line, shrinking them rather than breaking a word.
- Windows 3.1 games start again: Windows for Workgroups 3.11 stopped with "Invalid VxD dynamic link call to device number 0007" and quit to DOS.
- Games whose Sound Blaster changes sample rate no longer stop with "SB: the mixer needs N frames, the queue holds M".
- A Sound Blaster and a Gravis UltraSound set to the same DMA channel share it, as in DOSBox; the Gravis UltraSound no longer removed the Sound Blaster.
- DOSBox-X setups keep their Sound Blaster: settings for a second sound card no longer replace the first card's.
- The Gravis UltraSound no longer stops a game that starts its DMA before setting it up.
- A program that single-steps itself no longer hangs at the DOS prompt.
- Windows 3.1 programs that open their own program file (Director projectors) start: file locking is off, as in DOSBox 0.74.
- A game can make folders inside its own installed folders, such as its save folder.
- A hard disk image mounted with its geometry (`-size`) mounts, CD images go on the IDE bus where the setup puts them, a drive letter written with its colon (`mount d: CD`) mounts, and BOOT starts a disk image named from the setup's folder.
- Collection Chamber installers whose program runs to hundreds of megabytes no longer run out of memory while the launch is worked out.
- Shipped controls never put Esc on Start: where a game had Esc on Start, Esc moves to Select and Select's binding moves to Start.

Install over v1.6.0 or any v1.6.1 test build to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
