# v0.9.16

- Add RetroArch Slang shader selection in Graphics, with Off as the default, three bundled presets (Sharp bilinear, Sharp bilinear + scanlines, and CRT EasyMode), and shader ZIP import.
- Apply shader changes during a running game and redraw the DOS picture after switching shaders or recreating the display surface.
- Remove redundant setting summaries from menus with multiple options and simplify the Graphics popup title.
- Add setup instructions for launching games from iiSU and Beacon.
- Shader-enabled builds use GPLv3 terms; the bundled shader and runtime notices are available in About → Licenses.

Install over the previous signed KairoDos release to keep its games and settings. Both APK variants and the Play bundle include the same shader options.
