# v1.5.3

- The D-pad is the arrow keys alone: it no longer moves joystick 1 at the same time. The left stick is still joystick 1.
- Wizard's Crown: the D-pad sends the numeric keypad's keys alone, which the game reads for moving and in its menus.
- Yo! Joe!: X no longer presses Down and Space together; press Down and A to change weapon.
- Every controller button sends one thing per press, in every game's default controls.

Install over v1.5.2 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
