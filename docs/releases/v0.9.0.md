- First tagged KairoDos release, using DOSBox Staging 0.83.0 with the ARM64 dynamic CPU core.
- Includes shared Kairo library browsing, catalog updates, controller setup and mapping, graphics settings, on-screen keyboard, and dual-screen support.
- Includes catalog-driven With Sticks profiles for Doom and Duke3D, analog mouse control, and configurable key cycling.
- Uses the public metadata catalog without bundled game artwork. Games and proprietary system files are not included.
- The APK and Google Play bundle use the same application code and assets, package `com.loxifi.kairodos`, and persistent Kairo release signing key. Previous locally debug-signed DOS installations have a different signing certificate and cannot be updated in place with this release. Preserve their data; do not uninstall them merely to bypass the signature check.
