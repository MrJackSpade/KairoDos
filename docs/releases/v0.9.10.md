# v0.9.10

- Catalog installation and updates check the file format without scanning every game or decoding and hashing every image. Full first-party content audits remain in the publishing pipeline.
- Download checksums are calculated during transfer. Installed artwork packages activate atomically without a second full archive copy; failed downloads retain the previous catalog.
- Artwork packages include a compact runtime header and index for faster installation. Update the app to 0.9.10 before importing the new packages; previously downloaded packages remain supported.
