# v0.9.15

- Restore D-pad and controller hat navigation on the game detail page, including Play, Game settings, and off-screen actions.
- Add draggable left and right circle pads. Their thumbs can extend beyond the outer ring while retaining the intended movement range.
- Enable both on-screen sticks by default for With Sticks profiles and place them below the D-pad and buttons.
- Remove the initial With Sticks highlight from touch-device setup until a choice is selected or controller navigation begins.
- Move custom program launch and DOS prompt access from Game settings to a command-prompt button beside Play. Play uses two-thirds of the action row; the browser offers Prompt at its root and supports EXE, COM, BAT, and CMD selection.

This release replaces the failed v0.9.14 builds, which stopped before compilation because their release notes were missing.
