# KairoDos 0.9.8

Fixes cross-platform artwork archive checksums that prevented the 0.9.7 release workflow from publishing. ZIP headers are now identical on Windows and Linux, with a regression check in CI.

Retains the 0.9.7 catalog split: all sanitized game metadata and controls in every build, additional artwork catalogs in GitHub APKs, and reviewed artwork references only in the Play bundle. The with-images APK includes the image payloads.

The separate `kairodos-art.nsfw.zip` download carries its own revision and update manifest. Import it using **Import catalog file**.
