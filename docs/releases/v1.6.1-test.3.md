# v1.6.1-test.3

Test build of KairoDos, for DOS games. It is not published to Google Play.

- Collection Chamber games: put a Collection Chamber download (its Install-*.exe, with any .D01 parts beside it) in your DOS folder. The library lists it as the game's installer; Play installs it and starts the game its shortcuts start, with the DOSBox setup the download brings, then offers to delete the installer, as with eXoDOS. No catalog entry is needed for this.
- The catalog knows every Collection Chamber DOS and Windows 3.1 installer, before and after installing: it joins the eXoDOS game where there is one, and the others have their own title, tags, box art, screenshot and description.
- Two Collection Chamber downloads use Inno Setup installers, which are not supported yet.

Install over v1.6.1-test.2, v1.6.1-test or v1.6.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
