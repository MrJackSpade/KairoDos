# v1.3.1-test.1

Test build released alongside Kairo98 v1.3.1-test.1. It is not published to Google Play.

- KairoDos now runs on the frontend shared by every Kairo app, with a new icon.
- One library entry per game: a game's other releases in the folder sit behind its main release.
- Opening the app is faster: the library check reads again only the folders that changed, and game ZIPs are read in place instead of being copied to internal storage first. ZIPs on an SD card no longer fail with "Permission denied".
- **Download missing images** shows its progress and failures, downloads several images at once, takes LaunchBox artwork first, and waits out a server's rate limit instead of counting it as a failure.
- Default controls leave no button unbound, and A is Enter in games whose controls set only the D-pad, such as Amazon Snake.
- The bottom-screen keyboard has a **Joystick** tab that shows, maps and sends joystick input.
- In a game with its own button mapping, **Controls** names that mapping and lists the all-games mapping separately.
- The D-pad scrolls settings pages and the menu with the selection, choice rows always show their ‹, and the controller icon no longer flashes after touching the bottom screen.
- KairoDos tells you when a newer release is on GitHub.

Both APK variants have the same features.
