# KairoDos 0.9.7

All reviewed titles, softened descriptions, matching information and controls are available in every distribution. Catalog data, controls and artwork are separate files.

GitHub APKs include the additional artwork catalog. The with-images APK also includes its images; the smaller APK downloads images for games in your library. The Play AAB includes only reviewed artwork references. The same import, update and removal features are available in both distributions.

Optional artwork can be installed through Android's file picker using the separate `kairodos-art.nsfw.zip` release download. Only installed catalog update sources are checked.

Artwork outside the positive review whitelist remains restricted, including uncertain images.
