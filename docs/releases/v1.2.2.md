# v1.2.2

- **Controls › On-screen controls** is now Auto, Shown or Hidden. Auto hides the on-screen controls while a physical controller is connected and brings them back when it disconnects. An earlier explicit on or off becomes Shown or Hidden.
- The guest keyboard has a controller tab: tap a key, then press a controller button to map that key in the running game's profile.
- The DOS keyboard has a NUM page with an IBM keypad and Num Lock, and FN adds Print Screen, Scroll Lock, Pause and Shift. A physical keyboard's keypad, lock, Print Screen and Pause keys now reach the guest.
- Batman: The Movie has a controller profile that sends the game's own keys (Q, A, O, P and Space).
- RGDS: the keyboard and game screens stay paired when either goes to the background, and the volume keys work on every screen.
- Confirmation dialogs only fill the focused button, so the highlighted choice is the one A presses.

Install over v1.2.1 or a v1.2.2 test build to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
