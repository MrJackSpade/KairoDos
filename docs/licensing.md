First-party KairoDos source is GPL-2.0-or-later; see `COPYING`. The pinned Kairo frontend's first-party code uses the same license. Its generated Spleen font asset remains BSD-2-Clause and its source and full notice are in `shared/third_party/spleen/`.

No DOSBox Pure code is imported or packaged yet. Before distributing an emulator binary, audit its exact DOSBox Pure snapshot and transitive licenses, preserve notices, and provide complete corresponding source, including the pinned shared frontend commit.
