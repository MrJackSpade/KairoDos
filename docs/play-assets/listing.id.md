# Google Play listing: Indonesian (id)

- **App name:** KairoDos

## Short description

Mainkan game DOS Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

KairoDos memungkinkan Anda memainkan game DOS milik Anda sendiri di Android. Tambahkan folder, pilih game dari pustaka, lalu mainkan dengan kontroler atau kontrol di layar. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game tidak disertakan, dan beberapa game memerlukan pengaturan tambahan.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases KairoDos. Versi Google Play memiliki fitur yang sama.

KairoDos adalah proyek independen yang dibangun di atas DOSBox Staging.
