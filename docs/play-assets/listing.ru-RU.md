# Google Play listing: Russian (ru-RU)

- **App name:** KairoDos

## Short description

Играйте в игры для DOS на Android с сенсорным управлением или геймпадом.

## Full description

KairoDos позволяет играть в ваши собственные игры для DOS на Android. Добавьте папку, выберите игру в библиотеке и играйте с контроллером или с экранным управлением. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры не входят в комплект, а некоторым из них нужна дополнительная настройка.

Это же приложение можно бесплатно скачать в GitHub Releases KairoDos. В версии из Google Play те же возможности.

KairoDos — независимый проект на основе DOSBox Staging.
