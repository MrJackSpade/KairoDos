# Google Play listing: Korean (ko-KR)

- **App name:** KairoDos

## Short description

DOS 게임을 터치 컨트롤이나 게임패드로 Android에서 플레이하세요.

## Full description

KairoDos로 가지고 있는 DOS 게임을 Android에서 플레이할 수 있습니다. 폴더를 추가하고 라이브러리에서 게임을 고른 다음, 컨트롤러나 화면 컨트롤로 플레이하세요. 화면이 두 개인 휴대용 기기에서는 게임과 컨트롤을 서로 다른 화면에 표시할 수 있습니다.

게임은 포함되어 있지 않으며, 일부 게임은 추가 설정이 필요합니다.

같은 앱을 KairoDos GitHub Releases에서 무료로 다운로드할 수도 있습니다. Play 버전에도 같은 기능이 있습니다.

KairoDos는 DOSBox Staging을 기반으로 한 독립 프로젝트입니다.
