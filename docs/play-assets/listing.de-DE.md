# Google Play listing: German (de-DE)

- **App name:** KairoDos

## Short description

Spielen Sie Ihre DOS-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit KairoDos spielen Sie Ihre eigenen DOS-Spiele auf Android. Fügen Sie einen Ordner hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Controller oder der Bildschirmsteuerung. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele sind nicht enthalten, und manche brauchen eine zusätzliche Einrichtung.

Sie können dieselbe App auch kostenlos über die GitHub Releases von KairoDos herunterladen. Die Version bei Google Play hat dieselben Funktionen.

KairoDos ist ein unabhängiges Projekt auf Basis von DOSBox Staging.
