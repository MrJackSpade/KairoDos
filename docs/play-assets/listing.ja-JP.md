# Google Play listing: Japanese (ja-JP)

- **App name:** KairoDos

## Short description

Android で、お手持ちの DOS ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

KairoDos は、お手持ちの DOS ゲームを Android で遊べるアプリです。フォルダを追加してライブラリからゲームを選び、コントローラーまたは画面上のコントロールで遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームは含まれていません。一部のゲームには追加の設定が必要です。

同じアプリを KairoDos の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

KairoDos は、DOSBox Staging をベースにした独立したプロジェクトです。
